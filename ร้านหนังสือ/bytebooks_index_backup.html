Guide for Beginners

มือใหม่หัดเริ่มเรียนคอมพิวเตอร์ ควรเริ่มเล่มไหนก่อน?

หากคุณยังไม่แน่ใจว่าจะเริ่มต้นเรียนด้านไหน เราแบ่งเส้นทางการศึกษาออกเป็น 3 สายหลักที่แนะนำ:

1

สายเขียนโปรแกรม (Programming)

แนะนำเริ่มที่ภาษา Python หรือ JavaScript เพื่อเข้าใจตรรกะและลอจิก ก่อนต่อยอดสู่ Web/App Dev

2

สายข้อมูล & AI (Data & AI)

เริ่มต้นด้วย SQL & Python สำหรับจัดการข้อมูล ต่อด้วย Machine Learning และ Generative AI

3

สายระบบ & เน็ตเวิร์ก (DevOps & Security)

ปูพื้นฐานจาก Computer Architecture & Network แล้วต่อด้วย Docker, Linux และ Cloud
