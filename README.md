# ByteBooks - แบบเว็บไซต์ร้านหนังสือคอมพิวเตอร์ (Minimal & Clean UX/UI)

เว็บต้นแบบ (Interactive Prototype) สำหรับร้านหนังสือคอมพิวเตอร์และเทคโนโลยี ออกแบบภายใต้แนวคิด **"Clean, Focused, and Intuitive"** ใช้งานง่าย สบายตา ค้นหาสะดวก

---

## 🎨 แนวคิดการออกแบบ (Design Philosophy)

1. **เน้นความเรียบง่าย สบายตา (Minimalist & High Readability):**
   - ใช้โทนสีขาว-เทาอ่อน (`#f8fafc` / `#ffffff`) เป็นพื้นหลังหลัก เพื่อให้สายตาผู้ใช้อยู่ที่ตัวหนังสือและปก
   - แซมสีน้ำเงินเทค (`#2563eb`) เพื่อสื่อถึงความเชี่ยวชาญด้านคอมพิวเตอร์และเทคโนโลยี
   - ตัวอักษรใช้ฟอนต์ **Prompt** ผสมผสานกับ **Inter** ทำให้อ่านเนื้อหาภาษาไทยและคำศัพท์เทคนิคภาษาอังกฤษได้อย่างลงตัว

2. **ค้นหาและเลือกดูได้รวดเร็ว (Instant Discovery):**
   - **Live Search:** พิมพ์ค้นหาตามชื่อหนังสือ ภาษาโปรแกรม (เช่น Python, React) หรือชื่อผู้แต่งได้ทันที
   - **Category Pills:** แท็บหมวดหมู่แบบกะทัดรัด (การเขียนโค้ด, AI & Data, Cybersecurity, Cloud & DevOps, พื้นฐานคอมฯ)
   - **Sort Filter:** เรียงตามยอดนิยม, มาใหม่, หรือราคาได้ทันที

3. **ข้อมูลครบถ้วนโดยไม่ต้องเปลี่ยนหน้า (Frictionless UX):**
   - มี **Modal แสดงรายละเอียดหนังสือ:** บอกสารบัญย่อ, จำนวนหน้า, ระดับความเหมาะสม (สำหรับผู้เริ่มต้นหรือปานกลาง)
   - **Slide-out Cart:** ระบบตะกร้าสินค้าเลื่อนเปิดจากด้านข้าง ปรับจำนวนเล่ม หรือลบรายการได้ทันที
   - **Learning Path Guide:** ส่วนแนะนำมือใหม่ว่าควรเริ่มเรียนสายไหนและอ่านเล่มไหนก่อน
